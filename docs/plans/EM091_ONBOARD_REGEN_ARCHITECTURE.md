# EM091 — experimental onboard regenerative braking (0.1.102)
Owner approved calibrated classical model (EM090B) with native brake signal, actual speed change, no speed writes and no virtual kinetic reservoir. Exact baseline 0.1.101. This isolated stage accepts recovered energy into a real loco's existing logical onboard store; network-first export remains EM092, not a changed owner priority.

## Native debit boundary
- `brake_recovery_091.begin` runs before bridge/rail/helper/paid-traction phases; `finish` runs immediately after paid traction. Prior end-of-phase native burner J minus current pre-phase native burner J measures the intervening debit in a controlled, unchanged native consist. `train_energy_088` records receipts only after successful paid grid/store transfers; verify current post-phase J equals pre J plus all receipts for that physical engine. Require empty fuel inventory, internal fuel item, real EM loco or authorized native helper in the same live train/force/surface. Factorio 2.1.24 `currently_burning.name` is an item prototype (not just a string). First observed nonzero unverified J cannot certify. No credit from diesel/mixed untrusted engines. Neither cumulative grid credits nor store discharges alone certify mechanical acceleration.
- Stable ordered physical stock IDs, train ID, force/surface, weight, brake coefficients, direction, leading air, power caps, consecutive samples, pre/post state; train-created event invalidates affected epochs. Runtime setting change and configuration change invalidate; disk save retains the numeric certificate, never live Lua objects or old phase permissions. Damage event globally invalidates active epochs, including obstacle damage on the tested collision; intentionally conservative, may suppress unrelated trains in combat (scope refinement needed). A native damage event can occur *after* mod on_tick: ordinary pre-collision work credited earlier on that tick remains legitimate; actual crash interval is rejected on next sample. Not a general anti-tamper guarantee against arbitrary third-party scripts, no universal collision detector.
- `brake_estimator_091` is the exact EM090B diagnostic formula: C=450, eta=.65, 2 MW trial per real loco, .5 MW per motor wagon, helper brake in denominator only. Starts certified at clean rest. Every positive K change must be <= authenticated debit (bounded numeric tolerance); if not, reject until next clean rest. Both consecutive native `braking` flags mandatory, accepts only tested manual-control-stop and automatic arrive_station; zero/terminal, coast, abnormal and unsupported states receive no offer. On manual stop B/M; on station approach conservative passive subtraction and nominal cap. Coefficients and efficiency are experimental, not SI measurement or final game balance.
- Finite per-loco receiver, same rate/cap as existing EM089 charge, no charge/discharge on same physical store in same tick. Deterministic owner unit ordering. Unaccepted candidate J discarded; no virtual energy reservoir, no grid export, no new wagon batteries. EM089 grid-charge counter unchanged; new regen_J, `charged_J+regen_J=stored_J+discharged_J+lost_J`; recovered total equals credited; estimate=recovered+rejected. For finite-source QA with no untrusted added energy, subtract cumulative regen from the existing paid/returned accounting to avoid double counting reused J. Separate counters track authenticated native debit and cumulative hypothetical/actual grant. Engine reserve is still a separate finite quantity.
- Opt-in runtime-global `em091-experimental-regeneration` false by default, also requires EM089 storage enabled. No owner install/release. EM089's historical settings description is not updated in this experiment; use separate EM091 switch. No moving-grid-charge changes. No full braking GUI/manual driver/signals/reverse coverage, no Windows/MP or 60 UPS claim.
