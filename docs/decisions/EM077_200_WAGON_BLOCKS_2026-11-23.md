# EM077 — тяговый арифмометр по блокам из 200 вагонов (23.11.2026)

Владелец **утвердил** масштабирование штатной нативной тяги: при N моторных вагонах на одно реальное направление электровоза q=floor(N/200) полных помощников по 100 МВт и один остаточный помощник на r×0,5 МВт, если r=N%200>0. Примеры: 201 = 100+0,5 МВт; 400 = 100+100 МВт; 401 = 100+100+0,5 МВт; 800 = 4×100 МВт.

Каждый помощник — настоящий нативный локомотив Factorio, крепится в **свободную отдельную сцепку** одного реального состава. Для встречных направлений наборы независимы; два одинаково направленных настоящих локомотива не дублируют набор. Все 256 исторических прототипов сохраняются для совместимости, но новая схема использует не более 200 ступеней по 0,5 МВт на блок. Ванильные вагоны не меняются, запрещено вручную изменять скорость поезда. Электроэнергия оплачивается по настоящей сети, одна подстанция остаётся **20 МВт**, суммарная мощность повышается дополнительными стандартными подстанциями.

Нативное подтверждение на Factorio 2.1.24: 17/17 сценариев PASS на полной 0.1.77, реальный AUTO201 и power401 с 11×20 МВт. SAVE/LOAD, GUI, MP ещё не приняты. Изменения только в эксперименте, без слияния и релиза. Подробнее: [EM077 native QA](../research/EM077_BLOCK_TRACTION_NATIVE_2026-11-23.md).
