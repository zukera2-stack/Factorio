# EM072 0.1.63 FULL MOD — тест реальных предметов, без лабораторной карты

Это **ОДИН полный тестовый ZIP `ElectrifiedMainline_0.1.63.zip`**. Никакие отдельные C4/C5 моды не устанавливать. Все существующие рельсы ВСМ, опоры контактной сети, тяговые подстанции, электровоз, настоящие текстуры и электрораспределение EM070 сохранены из 0.1.62. Моторные грузовой и жидкостный вагоны в 0.1.63 — экспериментальные **настоящие** вагонные прототипы, но электротяга +500кВт за реальные джоули ещё НЕ работает. Электровоз всё ещё void-powered.

## Установка
1. Скачай **полный `ElectrifiedMainline_0.1.63.zip`** исключительно из GitHub Actions CI run ветки `experiment/em072-fullmod-player-test-063`. Снаружи GitHub отдаёт артефактный ZIP; распакуй его. Внутренний `ElectrifiedMainline_0.1.63.zip` положи **не распаковывая** в `%APPDATA%\Factorio\mods\`.
2. Убери/отключи предыдущий `ElectrifiedMainline_0.1.62.zip` и оба Base-only `em-c4-loco-mounted-probe_0.0.1.zip`, `em-c5-client-gui-observer_0.0.1.zip` (не удаляй пользовательские сохранения). Включи единственный `ElectrifiedMainline` + `base`. Factorio 2.1.24, сборка 87808 рекомендована, другой билд укажи отдельно.
3. **Создай новую временную карту.** Никаких автоматических полигонов при запуске; только по команде игрока.

## Минимальный тест GUI (1 команда и 1 скриншот)
1. На новой карте открой консоль и введи `/em-test-scene`.
2. Ожидается **одна короткая линия (29 настоящих рельсов ВСМ)**, **один настоящий EM-электровоз**, **один моторный грузовой**, **одна моторная цистерна**, **две мачты 25 кВ и одна тяговая подстанция**. Персонаж переносится к поезду. Скрытый 1MW нативный помощник — на нуле J и не является оплаченным источником тяги.
3. Кликни видимый электровоз, открой **обычное окно поезда** и пришли скриншот состава. Проверь, отображается ли дополнительный невидимый локомотив (его нативный слот может присутствовать); это главный C5 UX-gate.
4. Если команда выдаёт `SCENE FAIL`, пришли `factorio-current.log`. Ошибка запуска = FAIL, нельзя трактовать как успешный GUI тест.

## Проверка реальных предметов мода
Введи `/em-test-kit`, чтобы получить в инвентарь обычные **настоящие** предметы мода (ВСМ, контактные столбы север/юг, подстанции, электровоз, моторные вагоны, планировщик замены рельсов). Их можно строить **вручную** на пустой карте, проверять размещение, призраки, роботов, разборку и Undo/Redo. После выделения электровоза или вагона `/em-test-train` пишет реальные составы в `factorio-current.log`. Для электрических сетей имеется существующая `/em-25kv-status` и `/em-25kv-mode status`.

Не смешивай виды доказательств: предмет построился ≠ сеть питает поезд; GUI открылось ≠ Phantom скрыт; Lua/CI PASS ≠ реальное поведение в твоём клиенте. Тест ремонта Undo — отдельно зелёным Upgrade Planner, роботами и Ctrl+Z/Ctrl+Y; результат и log присылай по каждой геометрии.

**Не использовать на старом сохранении. Не сливать в main и не считать релизом.**
