# EM072-C5 — компактный пользовательский тест

**22.11.2026.** Тест только на новой одноразовой карте. Основной мод 0.1.62 не меняется.

## Установка
1. Скачай **только новый** [ZIP-артефакт компактного стенда](https://github.com/zukera2-stack/Factorio/actions/runs/45033425830/artifacts/14758132988) из успешной GitHub Actions сборки #45033425830 (исходный commit `e49bf01e0d88d4ccefb695824ff0d98a78f646f9`). **Старый архив из run 45032105889 создаёт огромный стенд и для этого теста не подходит.**
2. Распакуй наружный GitHub Actions ZIP. Два внутренних ZIP (`em-c4-loco-mounted-probe_0.0.1.zip` и `em-c5-client-gui-observer_0.0.1.zip`) положи в `%APPDATA%\Factorio\mods\` не распаковывая. Замени старые ZIP с теми же именами, если они есть.
3. В меню Factorio включи **Base + C4 + C5**, выключи остальные экспериментальные моды, перезапусти игру и создай новую пустую карту.

## Проверка
После появления в мире прямо рядом с персонажем автоматически создаётся **одна короткая линия из 29 рельсов** и **один состав из трёх видимых единиц**: настоящий EM-электровоз, моторный грузовой вагон и моторная цистерна. Скрытая четвёртая техническая единица привязывается на следующем тике. Других путей, станций и сотен вагонов нет. Автодвижение отключено; скрытый модуль получает **0 Дж** и не служит тестом оплаченной тяги.

**Никакие команды не нужны.** Щёлкни по **видимому** электровозу, открой штатное окно поезда и сделай один скриншот, чтобы видеть локомотивы/вагоны. При желании выдели поезд и введи `/em-c5-inspect` для записи состава в `factorio-current.log`.

**Критерий:** отображается ли невидимый технический локомотив отдельным слотом в штатном окне поезда? Передай скриншот и, если будет ошибка, лог `factorio-current.log`.

Нативный GUI, запуск на Windows, Blueprint/Undo/мультиплеер и EM070 J для этой версии пока **НЕ ПРОВЕРЕНЫ**.
