# Стандарт проекции подвижного состава Factorio (EM126–EM127)

Дата: 2026-11-27. Статус: калиброванный профиль для локальных QA-сборок 0.1.126–0.1.127; визуальная приёмка владельцем в Windows ещё не выполнена. Не означает, что эти сборки интегрированы в main: его проверенный базовый runtime остаётся 0.1.103.

## 1. Источник и принцип

Factorio использует диметрическое изображение объектов при квадратной игровой сетке. См. [FFF-133 — The train struggle](https://www.factorio.com/blog/post/fff-133). Не считать приведённый ниже эмпирический профиль точной внутренней формулой Wube: он получен сравнением собственных V2/V3 моделей с оригинальными PNG Factorio 2.1.25, 22 измерения (11 направлений грузового вагона + 11 цистерны), по bbox alpha >= 128, без теней и тележек. Нормированная RMSE fit: 0.25780572135198493 до, 0.09348760860846396 после. Масштаб и деформацию применять только к производной геометрии рендера; GLB и физические прототипы не изменять.

## 2. Воспроизводимый профиль

Локальные оси: X ширина, Y длина, Z вверх. GLB Y-up преобразуется поворотом +90° вокруг X и единым коэффициентом scale = 6.86 / extent_Z исходного GLB кузова Locomotive_v3_body.glb. У электровоза сохранить исходную привязку центра (см. render127.py: T[1,3] = mean(body.bounds[:,2])*scale); не центрировать каждый ракурс по bbox. Сначала проверить источники и их SHA256.

Камера ортографическая, наклон 45°, вертикальная ось кадра Z, 512×512 RGBA, parallel scale = 4, 64 пикселя исходного кадра на тайл, focal point (0,0,sqrt(2)). Для i из 0..255:

```python
theta = 2*pi*i/256
a = atan2(sin(theta)/sqrt(2), cos(theta))
sx = 1.3135771055323484
sz = 1.0
sy_e = 1.0
sy_n = 1.1804078422416089
sy = sy_e + (sy_n-sy_e)*cos(a)**2
x1, y1, z1 = sx*x, sy*y, sz*z
u = x1*cos(a) + y1*sin(a)
v = (-x1*sin(a) + y1*cos(a) + z1)/sqrt(2)
# Body frame: screen_x = 256 + 64*u
# screen_y = 320 - 64*v (ground origin); image shift {0,-1}
```

Камера (12*sin(a), -12*cos(a), 12+sqrt(2)). В прототипе scale=0.5, shift={0,-1}, apply_projection=false: коррекция направления уже запечена, повторно не применять. При i=0/128 продольная компенсация +18.0408%, при i=64/192 ноль; ширина +31.3577%, высота неизменна. Это визуальная компенсация, не реальные размеры вагона. Не подгонять глобальным увеличением. Новые модели калибровать на эталонах и сравнивать вертикаль, горизонталь, диагонали и повороты. В fit использованы сырые углы оригинального атласа, не уже скорректированные индексы.

## 3. Слои и атласы

| Объект | Направления | Слои |
|---|---:|---|
| Грузовой V2 | 128, back_equals_front=true | body / mask / shadow; закрытые люки во всех кадрах; 8 фаз отдельной анимации на каждой из двух осей |
| Цистерна V2 | 256, back_equals_front=false | body / mask / shadow |
| Аккумуляторный V2 | 256, back_equals_front=false | body / mask / shadow; 8 фаз вентилятора в каждом направлении |
| Электровоз V3 | 256, back_equals_front=false | body (сложенный пантограф) / mask / shadow / pantograph-up (замена крыши) |

Обычный атлас: ячейка 512×512, 8 столбцов × 4 ряда (4096×2048), 32 направления на файл, lines_per_file=4, line_length=8. Для тени электровоза EM127 ячейка 640×640, атлас 5120×2560, прежние scale/shift и центр (ground origin 320,384); не растягивать тень. Тени из геометрии, чёрный RGB, alpha; независимые тележки EM082 не деформировать и не перерисовывать вместе с кузовом. Геометрию сцепки joint_distance=4, connection_distance=3 не менять под картинку. Сохранять отдельные pivot/offset, без покадрового автоцентрирования.

Грузовые люки: движок может не рисовать нативный анимационный слой в движении, поэтому закрытая крышка должна присутствовать в основном кузове, в том числе на 0/64. Анимационные слои перекрывают закрытые проёмы с непрозрачным тёмным заполнением (не прозрачная земля). Только horizontal_doors и vertical_doors, 8 фаз; использовать настоящие шарниры из dimension_qa.json, не screen-space деформацию. Маски анимаций синхронны. Вентилятор: рендер полного кузова со штатной окклюзией, вычислить crop изменения и точный offset для каждого направления; не растягивать/вращать готовый 2D кадр. 256×8=2048 фаз. Пересчитать prototypes/battery_wagon_107.lua и scripts/battery_fan_offsets_108.lua вместе.

## 4. Окраска

Маску полосы строить в исходной UV-текстуре утверждённого материала, а не выделением красных пикселей всего готового кадра. Для конкретной палитры V2/V3 в EM126/127 coverage = clip((R-max(G,B))/(195-26),0,1); neutral = clip(RGB + coverage*([182,185,189]-[195,26,24]),0,255). Переносить matte с теми же камерой, геометрией, освещением тела/окклюзией (matte pass без освещения); grayscale mask, alpha не больше body alpha, прозрачный RGB=0. Цвет маски хранит освещённую яркость; apply_runtime_tint=true, flags={"mask"}, для вагонов tint_as_overlay=false. Не перекрашивать клапаны, фары, металл, крышу или пантограф. Для иного UV-материала повторно проверить сегментацию, не считать формулу универсальным детектором красного.

EM126 scripts/train_livery_126.lua: событие on_entity_color_changed, постройка/сцепка, reconcile на миграции; реальные локомотивы как источник, при явной смене цвета — изменённый локомотив, иначе первый EM локомотив или реальный ванильный. Обновлять только EM вагоны и EM локомотивы, не технических помощников и не ванильные вагоны; отцепленный вагон хранит свой цвет. Не вводить ежетиковый опрос только ради окраски.

## 5. Цистерна: насосы

Существующую модель клапанов не переделывать ради помпы; после каждой коррекции измерять центры трёх клапанов в кадрах 0 и 64. EM126 (пиксели, 512×512): вертикаль x≈255.5, y=133.329/225.755/318.114; горизонталь y≈225.5, x=144.812/255.557/366.157. Преобразование base_z=(center_y-255.5)/64-1, spacing=(outer2-outer0)/128. Поля FluidWagonPrototype:
- tank_spacing=1.7293
- valve_to_valve_offset_when_horizontal={1.7293,0}; vertical={0,1.4436}
- base_valve_xy_offset_when_horizontal/vertical={0,0}
- base_valve_z_offset_projected_when_horizontal=-1.4708; vertical=-1.4648.

Сохранять ванильный насос и параметры жидкости. Проверка 12/12 подключений и перекачки в native Base/Space Age; совпадение наконечника с клапаном на экране — отдельная Windows-проверка.

## 6. Пантограф V3 (EM127)

Электрическая привязка неизменна: продольная координата контакта -0.98115, вертикальное проекционное смещение 2.8728125 тайла, высота в авторском ортографическом пространстве 2.8728125*sqrt(2). Это не физическая высота. L=1.12 тайла длина каждого из двух рычагов. При деформации продольной координаты основания B, сохранить поднятый конечный шарнир E. D=norm(E-B), 0<D<2L; M=(B+E)/2 + (0,-(E_z-B_z)/D,(E_y-B_y)/D)*sqrt(L²-D²/4). Перенести шарниры, повернуть жёсткие рычаги; не масштабировать всю поднятую конструкцию как кузов. Для сложенного положения продольная координата конечного шарнира меняется вместе с основанием. Сохранять геометрию EM127: основание опущено на 0.18 относительно исходного шарнира, head width 0.5 от источника (историческая калибровка render127.py), сложенная высота конца B_z+0.08. Существующий contact anchor и traction scripts не менять ради картинки. Поднятый слой — замена изменённой области крыши с корректной alpha-композицией, без наложения на цветовую маску; не оставлять силуэт сложенного пантографа. Общая тень для сложенного кузова, отдельная поднятая тень пока не реализована.

## 7. Критерии приёмки

- Только настоящий рендер исходных GLB (EM126/127 выполнен VTK/EGL; Blender допустим при воспроизведении тех же геометрических параметров); не генерация изображения. Исходные модели read-only.
- Проверить все ячейки RGBA на полноту, альфу, минимум 2 px от края, одинаковые pivot и scale, маска не выходит за кузов, тень чёрная, неизменные участки анимаций. Проверять красный, синий и зелёный. EM126: 640 направлений каждого слоя, 2048 фаз вентилятора; EM127: 256 направлений каждого слоя, max head error=0, max composite pixels >16 intensity error=3 в кадре; фактический min padding body/mask/shadow/up=21/48/65/82 px.
- Native Factorio: прототипы Base/Space Age, окраска/сцепка/расцепление, насосы, холодный пуск. EM127 native 2.1.24 cold-auto и livery Base/Space Age PASS. Headless не доказывает визуальную корректность. Windows: один масштаб, параллельные пути с ванилью, 0/90/180/270° и диагонали, движущиеся люки, вращение вентиляторов, сцепки, тележки, провод/пантограф и насосы. Полная регрессия после графических правок, UPS и multiplayer отдельно; не заявлять окончательную приёмку.
- Direct Patch: архив с номером перехода, корневая папка всегда ElectrifiedMainline без версии, info.json с новой версией. Не заменять установленную игру без разрешения. Проверять исходную/целевую контрольную сумму и не обходить manifest gate.
