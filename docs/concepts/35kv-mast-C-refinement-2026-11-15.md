# Выбранный C — точный план уточнения опоры 35 кВ перед спрайтами

**Решение пользователя 2026-11-15:** вариант C «сбалансированный индустриальный» выбран из трёх художественных эскизов. Новая задача — доработка C2 перед переходом к игровым PNG. Выбор C принят, но **C2 ещё не создан и не утверждён**. Иллюстрация C находится в истории чата под именем «эскиз_индустриальной_железнодорожной_мачты.png», бинарное изображение не находится в репозитории.

## 1. Сохранить характер C
- Стройную четырёхгранную стальную решётчатую мачту с видимыми X-связями.
- Понятную одностороннюю Г-образную консоль и один диагональный подкос.
- Изолятор/зажим ниже конца консоли: ясное место подвеса.
- Стальной графитовый тон, достаточный контраст на песке/земле/тёмных плитках.
- Небольшие анкеры, компактную пяту и аккуратную наземную тень.

## 2. Обязательные уточнения C2

| Область | Сохраняем | Уточняем |
| --- | --- | --- |
| Основание | Металлическая опорная пластина и анкеры | Уменьшить тяжёлый бетонный постамент; визуально вписать в существующий 1×1 footprint; collision_box не менять |
| Стойка | Вертикальная решётка | Контрастнее грани и диагональные связи, меньше невидимой в игре болтовой мелочи |
| Консоль | Простая Г-форма | Одна главная горизонтальная балка + нижний раскос, без наращивания дополнительной тяжёлой фермы |
| Изолятор | Подвес у конца балки | Крупнее читаемый набор дисков, короткий зажим с однозначной точкой крепления |
| Верхняя линия | Верхний узел металлической мачты | На эскизе C через верх проходит дополнительный провод: НЕ включать его в игровой PNG мачты; если он нужен, реализовать в будущей отдельной системе проводов |
| Шкаф | Минимальные технологические детали | Убрать шкаф с молнией с типовой мачты: иначе визуально похожа на подстанцию |
| Жёлтая маркировка | Отличимость основания | Сократить яркую опасную полосу до небольшого предупреждения, не отвлекающего от ВСМ |
| Тень | Чёткую посадку | Согласовать с новой геометрией; общая статическая тень для восьми направлений сейчас может не совпадать с Г-консолью |

**Важно:** художественные масштабы и конфигурация электропроводки на иллюстрации не являются подтверждёнными инженерными размерами. Длинный контактный провод и несущий трос не встраивать в мачтовые спрайты: их формирует отдельный рендер-проход позже.

## 3. Три обязательные точки на точном C2
- **P0:** центр основания и координата существующей electric-pole в игре. Должен совпадать во всех восьми будущих кадрах.
- **P1:** место крепления Г-консоли к стойке. Должно быть читаемо, без плавающего соединения.
- **P2:** единственная визуальная точка крепления контактного провода у изолятора/зажима. Её нужно согласовать с будущей системой wire_anchor; длинные провода в мачтовом PNG не рисовать.

**Сначала подготовить один уточнённый эскиз C2**: крупный главный ракурс без длинных проводов, детали P0/P1/P2, мини-превью в игровом масштабе и один диагональный ракурс. Дать пользователю рассмотреть C2 и подтвердить/скорректировать. **Никаких финальных игровых спрайтов до согласования C2**.
