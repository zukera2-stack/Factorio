# Electrified Mainline 0.1.61 — локальные испытания на настоящем движке

**Дата:** 2026-11-21  
**Источник движка:** загруженный пользователем `factorio-headless_linux_2.1.24.tar.xz` (Linux x86-64).  
**Запущенная версия:** Factorio 2.1.24 build 87808 (`linux64`, `headless`).  
**Источник мода:** точный ZIP `ElectrifiedMainline_0.1.61.zip` из уже проверенного артефакта.

**SHA256 игрового ZIP:** `3771b7241848ae98e74019659baeb03616ab9aa4fa5dfcb9e7acf02efbef754c`.

## Результат

**NATIVE PASS — 2/2 сценария, суммарно 1350 игровых тиков, ~9,4 секунды полного цикла** (создание двух карт + запуск двух игровых тестов).

### 1. `em061-power-probe` — 1050 тиков

Движок создал железную дорогу и две подстанции, разделил заводские электросети и подключил общую контактную сеть. Тесты прошли:

- Прототипы и мод 0.1.61 загружены без Lua-ошибок.
- Электрические сети источника, потребителя и контактной линии физически разделены.
- Переменная режима интерфейса `primary-output` / `secondary-input` и ограничения потока доступны через нативный API.
- У приёмного интерфейса на контрольной отметке: **78 666 667 Дж**.
- У четырёх обычных аккумуляторов после зарядки: **7 140 000 Дж**.
- После отключения генерации на обратном направлении получено **5 940 000 Дж**, в аккумуляторах осталось **1 180 000 Дж**.
- Финальный маркер игрового теста: `[EM061 NATIVE PASS]`.

Это проверяет конкретный сценарий — не все возможные источники, батареи Bob's или динамическое изменение геометрии.

### 2. `em061-priority-probe` — 300 тиков

Шесть независимо построенных электрических сетей (отдельные нативные ID). На контрольной отметке 240 тиков:

| Режим | Состояние |
|---|---:|
| Заряженный ванильный аккумулятор → EEI `secondary-input` | EEI получил **1,2 МДж**, аккумулятор потерял 1,2 МДж |
| Заряженный аккумулятор → EEI `tertiary-input` | EEI получил **0 Дж**, аккумулятор не разрядился |
| EEI `secondary-output` → пустой аккумулятор | Аккумулятор получил **1,2 МДж** |
| EEI `tertiary-output` → пустой аккумулятор | Аккумулятор получил **0 Дж** |
| EEI `primary-input` против `secondary-input` при ограничении генерации 2 МВт | Первичный получил **8 МДж**, вторичный **0 Дж** |
| EEI `secondary-output` → `secondary-input` | **8 МДж** передано |

Финальный маркер: `[EM061 MATRIX PASS]`. Модельные обновления энергии кодом модов отсутствуют: энергетику рассчитывал игровой движок.

**Архитектурный вывод:** третичный вход/выход не является универсальным способом пересылки энергии между батареями. Для проверенных функций Electrified Mainline сохранить текущий мост с `secondary-input`/`secondary-output` до новых нативных проверок.

## Сведения о сохранности

Сценарии запускались на временных тестовых картах; исходники игрового мода не изменялись. Рабочую ветку `test/updater-approved`, стабильную `main`, патчер, 83 PNG и сохранения владельца не меняли. Файлы Factorio (бинарник и ресурсные архивы) не входят в инструментарий и не должны публиковаться в репозитории.

**Не проверено:** ARM64-архив (оборудование здесь x86-64), нативная энергетика модов Bob's, реальная физическая тяга локомотива, переход энергии через аккумулятор в двух перекрывающихся сетях, массовая зарядка через три подстанции, все сценарии сохранения/загрузки. Эти ограничения не отменяют успешно пройденные конкретные проверки.
