# EM072 — Контракт прицепных логических тяговых модулей по направлению (решение владельца, 2026-11-23)

**Статус: уточнение целевой архитектуры, НЕ реализовано и НЕ прошло нативную приёмку.** Остаётся экспериментальной веткой 0.1.71, без изменений `main`, релиза и пользовательских сохранений.

## Смысл

1. `em-motor-cargo-wagon` и `em-motor-fluid-wagon` являются реальными штатными `cargo-wagon` / `fluid-wagon`. Без настоящего `em-electric-locomotive` это только вагоны: 0 скрытых двигателей, 0 доступной моторной тяги, 0 токосъёма, 0 автономного движения. Их товары, жидкости, фильтры, насосы и обычные способы сцепки сохраняются. Наличие самостоятельного ванильного локомотива НЕ превращает их в EM-электромоторы.
2. Один настоящий EM-электровоз, сцепленный с 200 моторными вагонами, авторизует **один** скрытый агрегатный native-локомотив **100 МВт номинальной дополнительной мощности** (`200×500 кВт`), направленный по ориентации самого EM. У EM базовые 2 МВт: 102 МВт установленной мощности, **не гарантированное потребление**, поскольку настоящий источник, например 20 МВт, ограничивает суммарный дебет и тягу. Физическое ускорение — native Factorio, никакого `LuaTrain.speed` присваивания или фиктивного топлива.
3. В двухголовом составе с EM-электровозами противоположных направлений допускается **отдельный направленный скрытый двигатель на каждой реальной голове**. Оба описывают **ОДНУ совокупность моторных вагонов**; по ходу движения работает только соответствующая голова и её агрегат. **Нельзя суммировать мощность вагонов двух направлений**: 200 моторных вагонов дают максимум +100 МВт в выбранном направлении, а не +200 МВт одновременно. В двухголовом 1+200+1 установленная физическая мощность двух реальных EM равна 4 МВт, но полная номинальная тяга по одному выбранному направлению не должна некритично включать встречный EM как ещё +2 МВт. Проверить реальную направленную физику, включая нативный `reversing_power_modifier`.
4. Если несколько EM-электровозов смотрят **в одну сторону**, моторные вагоны учитываются **ровно один раз на это направление**. Не устанавливать скрытый агрегат по одному на каждый локомотив, иначе появляется двойная тяга. Владение следует закреплять за одним реальным EM по устойчивому `unit_number`, с восстановлением при демонтаже и переприцепке на полной остановке.
5. Вторая направленная приставка — не новая независимая батарея: у обоих скрытых native burner допустим лишь конечный, оплаченный из подтверждённой EM070 25кВ сети через собственный EM владелец запас. Спящий модуль не должен оплаченно заряжаться и не должен тратить энергию на встречную тягу. При демонтаже остаток запасённых Дж списывается в потери по принятому решению владельца; не возвращать их в сеть.
6. `LuaTrain.carriages` содержит технические локомотивы; GUI, расписание, сцепки, Undo/Blueprint, сценарии с двумя направлениями нельзя считать сохранными только потому, что один положительный headless-тест прошёл.

## Что **реально проверено в 0.1.71**, а что нет

- Официальный полный ZIP 0.1.71: **1 EM + 200 моторных вагонов + один скрытый агрегат 100 МВт, подключённый к реальным 20 МВт**, 651.277 клетки за 1200 тиков; 200 моторов + 2 EM **в одной голове** — 644.793 клетки; 256 моторов + 1 EM — 451.281 клетки. Это проверка передачи оплаченных J и нативной динамики тяжёлого состава, **НЕ** утверждение, что моторные вагоны могут ездить сами.
- Тест `200 моторных вагонов вообще без электровоза` **НЕ включён** в прежние 18 PASS; нужен отдельный жёсткий нативный отрицательный тест, в том числе отсутствие созданных скрытых агрегатов и отсутствие самодвижения после полной загрузки.
- Текущая 0.1.71 создаёт **ровно один** скрытый двигатель **на поезд**, наследует ориентацию только одного выбранного EM. Обратный рейс на втором конце провален: 68.973 клетки моторный vs 70.086 пассивный, скрытый моторный burner не расходовал тяговые J. Решение с **двумя направленными** двигателями ещё не реализовано и НЕ подтверждено безопасным.
- Натуральный локомотив Factorio способен на ослабленную заднюю тягу; **одного логического «выключателя питания» может быть недостаточно** для полной изоляции движущегося противоположно направленного технического локомотива. Это исследовательский риск, требующий замера native тяги обоих двигателей, а не догадки.

## Обязательные отрицательные и граничные тесты перед следующим PASS

1. **200 моторных вагонов без EM:** физически стоят без собственной тяги, груз/жидкость сохранны, 0 hidden helpers и 0 оплаченного моторам J. Также 1–2 моторных вагона без EM и с обычным vanilla loco.
2. **200 моторных + 1 EM:** именно +100 МВт добавочного номинала, один мотор, равная численность/сохранность вагонов; 20 МВт реального источника не превышаются.
3. **200 моторных + 2 EM навстречу:** по одному ориентированному модулю на каждое реально доступное направление; разгон и остановка влево/вправо, включая native AUTO-маршрут, положительный дополнительный путь относительно пассивного контрольного состава **в обе стороны**, без двойного расхода.
4. **2 EM в одной голове:** только один общий моторный агрегат на это направление, ни один вагон не посчитан дважды.
5. **0 Вт / нет контактной сети / 1 МВт дефицит:** нет бесплатного ускорения, нет зарядки встречного «спящего» бустера, реальный native sink не выдаёт больше оплаченного.
6. **Демонтаж левого/правого EM, разрыв состава, повторная сцепка, смена head, SAVE/LOAD:** обратная тяга не зависает, не теряется cargo, оплаченные J в уничтожаемых модулях учитываются как потери.
7. **256 вагонов на границе / >256:** не обещать больше поддержанного номинала; без неверного агрегата и без разрушения видимых вагонов.
8. **Ванильный GUI Windows, Blueprint/Undo, мультиплеер и UPS под нагрузкой:** по-прежнему отдельные незакрытые гейты.

**Запрещено выдавать этот контракт за внедрённый фикс.** Следующий шаг — независимый native-прототип двух направлений на реальном Factorio 2.1.24, и лишь после его удачи небольшой patch игровой 0.1.71 в новой ветке. `main` не изменять.
