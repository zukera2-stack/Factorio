# EM072-A5-B3 — проверка нулевого заряда, нативной зарядки и безопасного служебного терминала

Движок: Factorio 2.1.24 build 87808, официальный Linux headless. Исходный мод 0.1.62: точный CI EM071/EM070 ZIP SHA256 `91aef47ca13a0009e46ab92c9ad5735e0af30c6acc16bab1cf0507a8855a2575`. Предшественник: B1 PR #54, исследовательский успешный native тест 120MJ *предзаряженного* буфера через изменённую supply area одной опоры.

**Проверяемая гипотеза:** script-owned скрытый терминал `electric-pole`, подключённый строго одним native `pole_copper` проводом от `technical_046` hidden anchor через `wire_origin.script` и явно зарегистрированный в списке разрешённых портов, способен питать 24 нативных аккумулятора в изолированной контактной сети без расширения радиуса штатных мачт, сохраняя их нативный заряд, OFF и SAVE/LOAD. Контроллер аванпоста — отдельный placeable `electric-pole` с нулевым электрическим радиусом, не дающий скрытую электроэнергию.

**Аналоги:** собственный `prototypes/power_bridge_058.lua` (скрытый `em-25kv-bridge-port-058` с проверенным script-origin copper), `scripts/technical_network_046.lua` (audit и whitelist script-owned helper), `scripts/mast_network_059.lua` (mast→anchor), Base Factorio `small-electric-pole`, `accumulator`, `electric-energy-interface`. Документация API: https://lua-api.factorio.com/latest/classes/LuaWireConnector.html и https://lua-api.factorio.com/latest/prototypes/ElectricPolePrototype.html (актуальная версия, точные семантики проверяются нативно на 2.1.24).

**Проверки:** B3-0 outpost 24×0J на t1; B3-1 native заряд >0J без заявки поездов; factory и contact `electric_network_id` различны, отсутствует перекрытие фабричных источников с зоной outpost; B3-2 при 12×2MW Native engine выдаёт <=24MW и каждый поезд тратит native burner fuel; B3-3 при EM070 OFF после заряда outpost native выдача не превышает 7.2MW, factory энергия не падает после settle, движутся 12 поездов, полный баланс J замкнут; B3-4 native disk SAVE t151 → отдельный процесс LOAD с теми же числами; B3-5 audit не удалил разрешённый провод. Отрицательный тест: подключение терминала с неверной force/surface или к непроверенной мачте отклоняется.

**Ограничения:** прототипы, модификация whitelist и attach-remote только в одноразовой test копии CI ZIP; это не готовая автоматическая обработка blueprint/Undo, рецептов, train split/merge, factory brownout, rail cut/rejoin или multiplayer. Протокол запрещает объединять лабораторный PASS с производственным выпуском. В main ничего не меняется.
