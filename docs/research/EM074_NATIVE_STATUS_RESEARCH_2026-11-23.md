# EM074 — предупреждения электровоза и скрытых локомотивов (Factorio 2.1.24)

Дата: 2026-11-23. Экспериментальный мод 0.1.74, без разрешения на merge/release.

## Воспроизведение проблемы

В пользовательском Windows GUI 2.1.24 + ElectrifiedMainline 0.1.73 над реальным электровозом и техническим скрытым двигателем видна красная ванильная пиктограмма топлива, хотя фактический источник — контактная сеть 25 кВ. В пользовательском логе встречается `last_reason=no-contact`, а под действующим проводом оплата джоулей возобновляется. Технические двигатели невидимы, но имеют настоящий `BurnerEnergySource`, поэтому штатная иконка **ошибочно** вводит игрока в заблуждение.

## Штатный аналог и документация

- Установленный Factorio 2.1.24 build 87808: `factorio/data/core/prototypes/burner-usage.lua` задаёт `data.raw['burner-usage'].fuel` с `icon=__core__/graphics/icons/alerts/fuel-icon-red.png` и `no_fuel_status={'entity-status.no-fuel'}`.
- Factorio 2.1 [BurnerUsagePrototype](https://lua-api.factorio.com/latest/prototypes/BurnerUsagePrototype.html): `icon`, `no_fuel_status`, отдельные подписи ячейки топлива.
- Factorio 2.1 [BurnerEnergySource](https://lua-api.factorio.com/latest/types/BurnerEnergySource.html): поле `burner_usage` позволяет назначить отдельный визуальный тип одному виду двигателя; по умолчанию `fuel`.
- Штатный красный электрический значок: `__core__/graphics/icons/alerts/electricity-icon-red.png` — уже используется Base/Core Factorio. Прозрачный `__core__/graphics/empty.png` уже использовался в первоначальном моде.
- Прототип EM073: `prototypes/traction_paid_065.lua` (2 MW BurnerEnergySource) и `prototypes/em072_c5_fullmod_trial_063.lua` (ровно 256 конечных скрытых локомотивов, от +500 kW до +128 MW).

## Исправление — только интерфейс/прототипы

1. Отдельный burner usage `em-25kv-electric-status-074` только для `em-electric-locomotive`: статус `Нет контактной сети`, красный электрический значок вместо топлива.
2. Отдельный burner usage `em-hidden-motor-status-074` для всех 256 `em-c5-technical-booster-*`: полностью прозрачный значок, чтобы внутренние технические помощники не захламляли экран.
3. Обычный `data.raw['burner-usage'].fuel` и ванильный локомотив не меняются.
4. Не изменяются энергия, категории топлива, выделение оплаченных Дж, максимальная тяга, ориентация, скорость, сцепки, рисунки или обработчики событий.

**Ограничение:** статический `BurnerUsagePrototype.no_fuel_status` — замена надписи для случая **пустого нативного BurnerEnergySource**, а не вычисление текущей геометрии пантографа. Если провод есть, но нет напряжения, также может показываться «Нет контактной сети»; отдельное точное разграничение «нет контакта» / «нет напряжения» потребует новой динамической UI-логики и отдельных тестов. Нативный headless подтверждает загруженные прототипы, но не визуальный рисунок пользовательского окна — его проверяет владелец в Windows GUI.

## Критерии приёмки

- `Factorio 2.1.24` загружает полный мод 0.1.74 и все локализации без ошибок;
- `data-final-fixes` подтверждает **256 из 256** скрытых прототипов с прозрачным статусом, реальный электровоз с новым текстом и красным электрическим значком; vanilla `fuel` не затронут;
- в настоящем headless сохраняются source-paid 25 kV, 0 W / нет сети (0 Дж, 0 тяги), два электровоза в AUTO, 200 вагонов без электровоза, двухголовая моторизация, демонтаж и сохранность груза;
- реальные PNG: все 83 без побайтовых изменений;
- официальная GitHub Actions сборка и повтор нативных сценариев **на точном артефакте**;
- Windows GUI визуальный критерий окончательно принимает владелец после установки тестового ZIP.
