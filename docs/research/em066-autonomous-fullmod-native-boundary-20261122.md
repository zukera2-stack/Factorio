## 4. Falsification, tolerance, risk and rollback
- **Absolute energy**: check native generator `primary_output`, 25kV native `primary_demand/secondary_demand`, independent EEI `.energy`, loco burner J; never declare global conservation from two Lua counters using the same source increment. Explicit native 0W and no-contact cases must register 0 J future grants; allow bounded previously paid battery consumption.
- **Fairness**: two equally eligible real loco batteries, same authenticated 25kV network, source 1MW. Both should receive positive J during the FIRST 60 ticks once both contacts verified. A later catch-up is not sufficient.
- **Helper**: no hidden technical loco 80 ticks after true EM owner destruction; preserve original cargo/fluid and their unit IDs after separate-process LOAD.
- **Full mod**: all test runners load exact same full ZIP, no new tested sprite or mock replacement. Each game-source fix requires new branch source SHA, repackage complete ZIP, repeat BOTH lanes; do not retrofit old test result.
- **Abort/stop**: native API mismatch, incomplete mod list, absent artifact or wrong SHA, failed startup, unexpected hidden/free fuel, missing logs, private server SAVE failure, GUI unavailable (label NOT_TESTED); never silently mark PASS.
- **Rollback**: source test branches only. No main merge, release, patcher or modification of user's working saves/accepted art. PR draft and issue evidence on every failure.
