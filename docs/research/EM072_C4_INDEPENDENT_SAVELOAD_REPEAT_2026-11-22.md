# EM072-C4 — независимый повтор строгого нативного SAVE → LOAD

**Дата:** 22.11.2026. **Движок:** настоящий Factorio 2.1.24 build 87808 Linux Headless Base-only. **Область:** только исследовательский `em-c4-loco-mounted-probe` (без настоящей EM070, без игрового production-кода).

Один и тот же проверяемый source Lua fixture, встроенный Python-валидатор `tests/verify_c4.py`. Для **двух отдельно сгенерированных миров**: 365 нативных тиков, настоящий dedicated-server ZIP SAVE t125, полностью новый процесс Factorio LOAD +240 тиков. Во **всех двух** запусках валидатор подтвердил совпадение снимков движения, `train.carriages`, привязанных к владельцам вспомогательных локомотивов, отцепки/перестыковки, тиков 190/280/350, состояния AUTO/расписания/станции, 37 железных плит, 9000 воды, J технического `LuaBurner` до/после загрузки.

## Не закрытые риски

Ранее **другая, не принятая редакция стенда** дала измеренное SAVE/LOAD расхождение ~0,027343 тайла и 24,9 кДж; эксперимент с немедленной очисткой оставшейся энергии осиротевшего бустера тоже не прошёл строгую сверку. Повторная воспроизводимость **конкретного принятого исходника C4 теперь подтверждена в двух независимых мирах**, но **общая надёжность других вариантов, очистки осиротевших J и будущей EM070-схемы не доказана**. Такие отрицательные результаты нельзя считать устранёнными одной лишь повторяемостью данной версии.

Не проверены графический train GUI, куда входит скрытый native `locomotive`, кривые/диагонали/надземные рельсы, Blueprint/Undo/MP, настоящая оплата джоулей от 25 кВ и конечных батарей электровозов. Не менять игровые файлы или main.
