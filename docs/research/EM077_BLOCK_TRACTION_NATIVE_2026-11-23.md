# EM077 — 200-вагонные блоки настоящей моторной тяги, нативные испытания

**Дата:** 23.11.2026. **Ветка:** experiment/em077-block-traction-200-native-20261123. **Мод:** ElectrifiedMainline 0.1.77, экспериментальная рабочая сборка под Factorio 2.1.24.

## Принятое решение и реализация

На каждые полные 200 моторных вагонов — один скрытый локомотив на 100 МВт. Остаток получает ещё один скрытый локомотив с шагом 500 кВт. На одно настоящее направление движения это floor(N/200)×100 МВт плюс (N%200)×0,5 МВт, если остаток не равен нулю. Примеры: 200→[100]; 201→[100,0.5]; 400→[100,100]; 401→[100,100,0.5]; 800→[100,100,100,100]. Для двух противоположных направлений наборы раздельные, для одинаково направленных голов тяга не дублируется.

scripts/helper_lifecycle_067.lua: новая проверка и учёт набора помощников на направление, поиск **разных реальных свободных 7-клеточных сцепок**, перестройка блоков при изменениях состава. Нативная Factorio отказывала при попытке вставить второго помощника в ранее разрезанную сцепку: исправлено выбором следующей отдельной сцепки. При удалении помощника игра разрывала состав: теперь retire запоминает соседей и **нативно воссоединяет настоящие вагоны** без телепортации и без записи LuaTrain.speed. Есть страховка от перестройки на ходу и подготовка перепривязки дальнего помощника при загрузке сохранения, но настоящий SAVE/LOAD пока не подтверждён.

scripts/traction_paid_065.lua: убран прежний ошибочный **общий потолок 120 МВт** потребителя. Настоящий native EEI-запрос ограничивается реальным запросом состава и суммарным количеством активных 20-МВт мостов на проверенной контактной сети. **Не введена одиночная 120-МВт подстанция.** Энергия не создаётся из ничего, нативные горелки получают только дебетованные джоули.

prototypes/em072_c5_fullmod_trial_063.lua: изменены пояснения; все 256 прототипов сохранены как совместимость со старыми сценариями, вновь создаваемые блоки используют ступени лишь до 100 МВт. info.json: экспериментальная версия 0.1.77. Все 83 утверждённых PNG неизменны, интерфейс EM076 «Нет тягового питания» сохранён.

## Проверки настоящим Factorio 2.1.24 build87808, Linux x64 headless

**17/17 реальных нативных сценариев PASS на полном распакованном моде:** 1,199,200,201,400,401,600,800 вагонов; dual201, zero201, resize200, resize201, resize400, decrease201, loss201, auto201, power401. Сценарий tests/em077-block-qa/scenarios/native/control.lua — **точно тот же исходник, что использовался в успешных тестах**, проверен SHA Git blob 011d2ed4876b8ea4d2009001710870ae1b7974ae. Все сценарии сохраняли видимые вагоны и тестовый груз 37 железных пластин / 9000 жидкости, отсутствие бесплатной тяги при нулевом питании, корректные сцепки.

- auto201: настоящий автоматический поезд 201 моторный вагон, 2 скрытых двигателя, проехал **50,059 клеток за 300 тиков**.
- power401: 401 моторный вагон, 3 скрытых двигателя [100,100,0,5] МВт, 11 настоящих подстанций **по 20 МВт**, нативный EEI измерил **пиковый запрос 202,5 МВт** и реальное движение **138,254 клетки за 300 тиков**. Пиковый запрос — НЕ заявка на непрерывную передачу 202,5 МВт: суммарно дебетовано/зачислено 359966666,667 Дж.
- Отдельный 2830-тиковый тест электрической сети PASS: 1/2/3/6 ×20 МВт = 20/40/60/120 МВт в обоих направлениях, перегрузка не нарушает индивидуальный предел.
- Регрессия EM076 PASS: электровоз имеет красную электрическую иконку; 256/256 скрытых помощников с выключенной пиктограммой отсутствия топлива.

**Полный установочный ZIP тоже нативно загружен**; из точного ZIP сценарии 201 и EM076 PASS, ещё один скриптовый повтор первых восьми случаев (1–800) PASS, затем процесс повторной проверки прервался из-за лимита времени среды. Не называть это дополнительными 17/17 на ZIP.

Полный файл ElectrifiedMainline_0.1.77.zip: **SHA256 741a67285de59fd81cf95a7a2ef5654e1559d37a960039e0a7dfbc3f39b92fc6**, ровно **140 игровых файлов**, 83 графических PNG побайтно идентичны оригиналу 0.1.73 пользователя. Все четыре изменённых игровых файла идентичны исходникам в данной ветке GitHub **по blob SHA**. Отдельный QA ZIP с настоящими журналами и тестовыми скриптами создан локально (игровых бинарников внутри нет).
