# EM072-C4 — чёткие критерии PASS/FAIL для скрытого агрегатного привода

Источники: [отчёт C4](EM072_C4_LOCOMOTIVE_MOUNTED_BOOSTER_2026-11-22.md), [контракт EM072](../architecture/EM072_TRAIN_ENERGY_BUS.md), [C3](native-zero-length-helper-loco-072c3.md). Реальные нативные тесты в Factorio 2.1.24 build87808 Linux Headless; **в исходниках игрового мода нет реализации**.

**PASS подтверждено:** non-EM vanilla loco→0 helper; wagon-only→0 helper; 1/2/4 motor→500kW/1MW/2MW с одним агрегатом у одного EM; native acceleration с finite hidden lab J, нуль J без дополнительных acceleration; 14-tile видимый span; protected invisible prototype (not selectable, no item, not blueprintable/deconstructable/on-map; runtime minable false); 2 EM + 2 motor→один helper у одного реального владельца; удаление единственного EM→нет locomotive в составе вагонов; удаление владельца с ещё одним EM→helper удалён; 2→1→2 перецепка→tier 1MW/500kW/1MW, cargo 37 plate + fluid 9000 water и unit_number неизменны; AUTO schedule (real station) и deferred installation at station; main saved game benchmark 365, real server SAVE125 and independent LOAD+240 strict comparison PASS for one verified reproduction.

**Непрошедшее/непринятое:** в раннем candidate разница reload 0.027343 tile / 24930.733 J; дополнительный эксперимент с немедленным обнулением модуля от осиротевшего владельца дал ещё одно расхождение относительно benchmark. Причина не изолирована, production отложен. Варианты с VOID-питанием не могут войти в production. При удалении технический J должен вернуться в шину или быть явно записан потерей; штатный 10MJ seed теста недопустим.

**NOT TESTED:** реальная EM070 J, зарядка локомотивной батареи, возврат рекуперации, прямой GUI клиента/список локомотивов, видимость при наведение на состав, пользовательское/роботизированное строительство и демонтаж, curved/diagonal/elevated, настоящие массовые станции и светофоры, мультиплеер 60UPS. Любая из них может сделать текущую схему непригодной.
