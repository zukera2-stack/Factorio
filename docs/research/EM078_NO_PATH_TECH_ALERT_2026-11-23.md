# EM078 — графические предупреждения «Нет пути» у скрытых тяговых локомотивов

**Основание:** запись пользователя `Factorio 2026.11.23 - 20.40.59.02.mp4`, 7,8038 секунды, 1920×1080, 60 кадров/с. При реальном статусе поезда **«Нет пути»** в мире видно несколько мигающих жёлтых значков рядом с техническими локомотивами. Источник предупреждения — **поездная маршрутизация Factorio 2.x**, а не топливо `BurnerEnergySource`.

**ИСПРАВЛЕНИЕ:** `ElectrifiedMainline/prototypes/em072_c5_fullmod_trial_063.lua`, 256 прототипов `em-c5-technical-booster-*`: `p.alert_icon_scale=0` и `p.icons_positioning={}`. Видимым электровозам, vanilla, маршрутам, 20-МВт подстанциям, 200-вагонной арифметике мощности, оплаченной энергии, сцепкам, скорости и обработчикам событий ничего не меняем. Мод 0.1.78. Старый `render_no_power_icon=false` (от EM076) сохраняется: он применяется только к топливу, но не к поездному «Нет пути».

## Полный аудит источников графики скрытого локомотива
| Источник | Статус в исправлении |
|---|---|
| `pictures.rotated` (корпус, маска, тень) | прозрачное изображение 1×1, без изменений |
| `wheels.rotated` | прозрачное 1×1, без изменений |
| `front_light`, `back_light`, `stand_by_light`, `front_light_pictures` | отключены, без изменений |
| `minimap_representation`, `selected_minimap_representation` | отсутствуют, без изменений |
| `stop_trigger` | отсутствует, без изменений |
| `selectable_in_game`, `hidden_in_factoriopedia`, `flags` | нет выбора, пользовательского строительства и отображения на карте |
| `BurnerEnergySource.render_no_power_icon` | `false` у 256 скрытых двигателей, без изменений |
| `BurnerUsagePrototype.icon` | прозрачное изображение, без изменений |
| `EntityPrototype.alert_icon_scale` | **0 у 256 помощников**; у настоящего/ванильного локомотива положительный |
| `icons_positioning` | **пустая таблица**, не показывать топливный Alt-индикатор |
| `alert_icon_shift`, `icon` | унаследованные метаданные, сами по себе не являются причиной мигающей пиктограммы; не меняем |
| Поездное состояние `LuaTrain.state=no_path` | не вмешиваемся: игрок должен видеть настоящий дефект маршрута |

Функция `render_no_power_icon` относится к топливу (https://lua-api.factorio.com/latest/types/BaseEnergySource.html), а `alert_icon_scale` к значкам оповещений сущности (https://lua-api.factorio.com/latest/prototypes/EntityPrototype.html). [FFF-395](https://direct.factorio.com/blog/post/fff-395) описывает мигающую пиктограмму маршрута в Factorio 2.0+.

## Проверено на РЕАЛЬНОМ Factorio 2.1.24 build 87808 (Linux headless)

- Точный полный ZIP `ElectrifiedMainline_0.1.78.zip` SHA256 `a6b5433b5513a9755a53185a5063bbf41f8bf15a1fe625a20b720bc351d38163`, 140 игровых файлов, 83 PNG побайтово без изменений.
- **Data stage: 256/256 PASS**: подтверждены нулевые alert scales и пустые Alt-icons, невидимые корпус, колёса, миникарта, фары, неизменное отключение топливных значков, ненулевые alert scales видимых EM и vanilla.
- **5/5 runtime PASS**: настоящий `train.schedule` на несуществующую станцию, `manual_mode=false`, `train.state=defines.train_state.no_path` в нативном движке; случаи **201 (2 скрытых), 401 (3), dual201 (4), 800 (4), zero201 (2)**. Все реальные помощники имеют `LuaEntityPrototype.alert_icon_scale=0`, а настоящие EM — ненулевой.
- **17/17 fullmod EM077 регрессий PASS** на том же полном ZIP: `1 199 200 201 400 401 600 800 dual201 zero201 resize200 resize201 resize400 decrease201 loss201 auto201 power401`. Запущены последовательно после выявления общей блокировки экземпляров игры `.lock`; ранние ошибки одновременного запуска не являются дефектом мода.
- Исходники/тестовые сценарии доступны в этой же ветке; журналы локальных запусков переданы отдельно (без бинарников и приватных ресурсов Factorio).

**ВАЖНАЯ ГРАНИЦА:** headless проверил подлинное состояние no_path и принимаемый движком масштаб отображения 0, но не может показать кадр Windows GUI. Нужна визуальная приёмка владельца. **Один жёлтый индикатор над настоящим электровозом остаётся, пока «Нет пути» действительно имеет место**. Если после установки остались дополнительные, проверить скрин и источник: глобальная отрисовка поезда может отличаться от prototype entity alert scale.

**Установка:** только на копию сохранения, положить ZIP без распаковки в `%APPDATA%\\Factorio\\mods\\`, отключить 0.1.77. Владелец сохранил оригинальный ZIP и изображения; `main` не изменять, PR не merge, GitHub Actions вручную не запускать.
