## Границы и дальнейшая работа

- Это **однофайловая оптимизация маршрутизации**, не переписывание ванильной электрической физики, не увеличение пропускной способности и не изменение ограничений 20 МВт.
- Нет доказательства 60 UPS для 200 реально построенных подстанций с меняющейся нагрузкой; нет полноценной native проверки Bob's Power и multiplayer.
- Потерю скрытых EEI при разрыве, реконфигурации и разделении сетей требуется устранить либо физически обоснованно учесть отдельно. Демонтируемая подстанция по решению владельца теряет *собственный* буфер, а внешние аккумуляторы — нет.
- **Не переносить** экспериментальную 0.1.62 на `test/updater-approved` и не сливать в `main`: PR #42 остаётся draft до отдельного разрешения владельца.
