# EM072-A5 Buffer Outpost — первичное API-исследование без нативного испытания

**Основание:** предложение владельца 21.11.2026; полный [план аванпоста](../plans/BUFFER_OUTPOST_072A5.md). **Этот текст — API review/engineering hypothesis, а не результат Factorio runtime теста.**

1. [Factorio AccumulatorPrototype](https://lua-api.factorio.com/latest/prototypes/AccumulatorPrototype.html): `energy_source` отвечает за фактическую ёмкость; нативный accumulator entity по прототипу Base содержит buffer 5MJ, input/output 300kW. [Wiki](https://wiki.factorio.com/Accumulator) подтверждает charge on surplus, discharge on shortage, включая разделение двух соседних сетей аккумуляторами — это **дополнительный риск случайного factory/corridor объединения**.
2. [ElectricUsagePriority](https://lua-api.factorio.com/latest/types/ElectricUsagePriority.html): нативные аккумуляторы работают с managed/tertiary priority, динамические EEI мостов используют другие приоритеты; порядок factory surplus -> outpost charge и outpost -> native traction meter необходимо подтвердить именно Factorio **2.1.24**, нельзя выводить только из перечня типов.
3. [LuaEntity](https://lua-api.factorio.com/latest/classes/LuaEntity.html): `entity.energy` и `electric_network_id` доступны для измерения, но простое наличие энергии или того же force не доказывает, что аккумулятор и локомотив имеют одну реальную сеть. Требуется validated `technical_046.components`, native rail path и собственный terminal port.
4. Текущий `bridge_devices_060.lua` раз в 60 тиков собирает native accumulator `stored/capacity/charge/discharge` для разрешённых сетей; `bridge_dispatch_059.balance` применяет max к raw и direct snapshot для предотвращения дублирования. Будущий outpost должен пользоваться этим native учётом **не добавляя тот же запас ещё раз**.
5. `technical_network_046.lua` запрещает посторонние script copper connections у скрытых anchors; `power_bridge_058.lua` изолирует factory- и line-side EEI. Коридорный terminal для игроком размещаемого буфера — **новая задача**, а не уже существующее публичное API.
6. Условия для успешного pilot: измерить реальную native зарядку/разрядку 24 * 5MJ * 300kW аккумуляторов, утверждённую сетевую топологию, 20MW/станция, реальное питание от коридорного аккумулятора при OFF EM070, отсутствие двойного EEI demand и физический SAVE→LOAD. Если native line-side input meter не может быть безопасно подключён, **не вводить игровую сущность и не присваивать заряды через Lua**.

**Изученная отправная точка:** официальный Factorio API и реальный исходный EM070/technical046 из `main` 0.1.62. Нативный A4 ранее тестировал реальные 2 локомотива/2 подстанции и фабричные аккумуляторы на стороне источника; **прикреплённый к corridor buffer outpost там НЕ существовал**. 12 native поездов и 30 секунд пикового разряда **ещё НЕ тестировались**.
