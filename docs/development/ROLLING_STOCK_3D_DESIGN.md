## Owner requirements

- Motor cargo wagon: smooth body, opening oval covers (location and count to be decided on concept; no assumption of side placement); retain cargo function. Animated covers separate with hinge/pivot and open/closed state.
- Motor fluid wagon: single continuous tank, exactly three top filling/drain valves; preserve native connection and pump functionality. 
- Dedicated accumulator wagon: V3 design language, exactly four square roof battery modules, light protective grille, large fans; fans spin when connected to locomotive and current is present, stop when absent. Define and test actual powered-state predicate separately; do not invent capacity, power ratings, cooling consumption, number of fans per module or new battery physics before design approval. Not a battery added to ordinary motor wagons.
- All three use exact V3 locomotive bogie geometry, shared palette, shape language, painted red stripe (texture not raised geometry); no added independent pantographs. Keep original approved locomotive unchanged. Check wheel pivot, rail plane, clearance and coupling, do not blindly copy locomotive spacing.

2. Build editable parametric source/JSON and GLB using A3DS method B and archived V3 source. Common X width,+Y front,Z up; named hull/roof/hatches/valves/battery blocks/grilles/fans/bogies, stable pivots, UV livery. Render real geometry with calibrated camera; compare against approved sketch in side/top/front/hero and held-out angles; no false quantitative fidelity for uncalibrated art. Validate GLB readback, finite vertices, normals, topology, bounds, closure where appropriate, UV/material presence and actual V3 bogie identity. Record hashes and limits.
