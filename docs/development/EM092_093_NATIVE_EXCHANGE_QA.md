## Production blockers and next gate

Diagnostic copies rely on QA-only finite marker prototypes and pre-existing live station line ports. One global pending offer, cannot handle arbitrary simultaneous braking trains or networks; no general allocation/ownership or robust live topology revalidation across native solver interval. Source debit means energy accepted into real electrical system (possibly native intermediate storage), not necessarily terminal delivery; distinguish accepted source J and terminal J. Need deterministic per-port/per-consist pending queues, exact same-physical-line permission; guard against factory/corridor short, rebuild/port deletion, disconnect, multiple offers, stale native IDs, runtime-disable and disk reload with pending output, cross-force/surface, and ensure residual cannot be delivered twice or lost silently. Need stand-alone verified line terminal/traction sink without importing bridge and without even a substation, native connection lifecycle, no source reassignment to unrelated networks. Need define fair allocation when multiple braking and accelerating trains, network-first then own receiver; do not make test-only donor override authoritative. Retain 20 MW each substation. Then full integrated 12/24/100, long route, negative controls and old regression; isolated performance profiling, Windows/MP. Prior baseline is exact 0.1.102, no new version or patch.
