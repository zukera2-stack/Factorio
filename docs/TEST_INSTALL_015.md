## 2. Два ZIP — это нормально

GitHub отдаёт внешний архив артефакта (например, `ElectrifiedMainline-test-build.zip`). **Открой / распакуй только этот внешний архив**. Внутри должен быть файл:

```text
ElectrifiedMainline_0.1.15.zip
```

**Именно этот внутренний ZIP** положи в папку модов Factorio. Его **не нужно распаковывать**. Внутри него должна быть ровно одна папка `ElectrifiedMainline/` с `info.json`. На Windows стандартная пользовательская папка обычно `%APPDATA%\Factorio\mods` (если установка использует другой пользовательский каталог — выбери фактическую папку модов игры).

1. Сделай копию тестового сохранения.
2. Убери из `mods` старые ZIP `ElectrifiedMainline_0.1.14.zip` и `..._hotfix.zip`, а также другие копии этой же версии мода, чтобы не возникало конфликта.
3. Скопируй `ElectrifiedMainline_0.1.15.zip` в `mods`.
4. Запусти Factorio, проверь отображаемую версию мода `0.1.15` и открой **тестовое** сохранение.

## 3. Проверка без изменения игровых объектов

Наведи курсор на рельс ВСМ (или встань возле него) и введи в консоль:

```text
/em-35kv-preview 1
```

Появятся временные кружки с подписями `L` / `R` и линиями до **ориентира сигнала**, а не до гарантированной точки контактного провода.

- **Зелёный / CLEAR:** `LuaSurface.can_place_entity` не обнаружил препятствия в этом месте для прототипа опоры. Это **не означает**, что место геометрически правильно или разрешено правилами ВСМ.
- **Красный / BLOCKED:** проверка размещения возвращает запрет из-за столкновения.
- **Малиновый / API_ERR:** ошибка выполнения запроса; нужен лог.
- Компасное имя в подписи (например, `east`, `northwest`) — предполагаемое направление имеющейся графики консоли.
- Разметка исчезнет через **15 секунд**; настоящие опоры, рельсы, сигналы и Undo история не изменяются этой командой.

Когда разметка исчезнет, сравни:

```text
/em-35kv-preview 1.5
```

Дополнительно можно проверить `0.5` и `2`. Повтори эксперимент на **прямых, обеих разновидностях кривых и полудиагональных** рельсах ВСМ.

**Негативные проверки:** на участке только с обычными рельсами и без ВСМ в радиусе 10 клеток команда должна сообщить об отсутствии ВСМ без рисования маркеров; `/em-35kv-preview 4` должна показать правила ввода и ничего не рисовать.

**Что прислать:** скриншот с кандидатами и при необходимости `factorio-current.log`, а также предпочитаемое смещение и сторону для каждого типа рельсов.

## 4. Статус и ограничения

- **CI подтверждено:** [Lua 5.2 и ZIP, #43572452213](https://github.com/zukera2-stack/Factorio/actions/runs/43572452213); [проверка документации #43572508712](https://github.com/zukera2-stack/Factorio/actions/runs/43572508712).
- **Скриншот пользователя 0.1.14:** четыре подписанные точки рельсового сигнала возле **одного** участка ВСМ; не доказательство геометрии опор 0.1.15 и не проверка всех четырёх форм рельсов.
- **Не проверено в игре:** работа команды 0.1.15, правильность направлений и смещений на кривых/диагоналях, занятость мест реальными объектами.
- **Не реализовано:** установка опор исключительно у ВСМ, автоматический snap, передача мощности 35 кВ, питание поездов. Реальные железнодорожные сигналы в эксперименте не создаются.
