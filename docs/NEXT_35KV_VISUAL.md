# Точка продолжения — 35 кВ: визуал опор

**Приоритет (решение пользователя 2026-11-14):** **сначала эскизы → затем спрайты → затем тест в Factorio**. После принятия игрового вида опор — красивая контактная сеть проводов над ВСМ. После принятия проводов — электрическая логика. Не менять этот порядок без отдельного согласования.

**Единственное следующее практическое действие:** изготовить и показать пользователю **3 эскиза** A — лёгкая решётчатая, B — усиленная мачта, C — сбалансированная индустриальная. К каждому: основание, Г-консоль, изолятор, точка подвеса, пример на прямой, кривой и параллельных путях. **Только после явного выбора одного варианта переходить к 8-направленному комплекту спрайтов. Только после готовых спрайтов строить ZIP и тестировать в игре.**

**Не разрабатывать сейчас:** перехват ЛКМ, капсулы, специальные грунты, временные семафоры, новые сущности, реальную передачу мощности. Физическая опора может стоять вне ВСМ, но в визуальную контактную сеть подключается только рядом с рельсами ВСМ. Источники: `scripts/power_019.lua` / `scripts/power_topology.lua`. Пробная 0.1.20 `capsule + place_result` **провалена в игре**: [отчёт](https://github.com/zukera2-stack/Factorio/blob/feature/catenary-item-click-probe-020/docs/tests/catenary-click-probe-0.1.20-game-fail-2026-11-14.md).
