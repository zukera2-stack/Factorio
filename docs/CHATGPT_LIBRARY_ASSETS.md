## Обязательная последовательность для будущих агентов

1. Проверь GitHub HEAD, `AGENTS.md`, `docs/CURRENT_WORK.md` и документы **выбранной ветки**; не подменяй код архивами из библиотеки.
2. Если подключена личная библиотека ChatGPT пользователя, явно открой папку `/Мод фактроио/` **по полному пути**, а также при необходимости `/Factorio/`. Не ограничивай поиск файла общим поиском по всей библиотеке: он может не показать архив движка.
3. Для локальных тестов сначала ищи `factorio-headless_linux_2.1.24.tar.xz`; на x86_64 **не** используй ARM64. Найди оригинальный ZIP тестируемой версии и его SHA256 из журнала/официального CI. Проверяй реальные хеши полученных байтов.
4. **Прежде чем обещать запуск**, проверь возможность законно получить исходные байты и реально запустить `factorio --version`. Если материализация отказана, зафиксируй отказ; не обещай и не имитируй игровой PASS. GitHub Actions не запускать, если владелец явно запретил.
5. Для масштабирования подстанций `1/2/3/6 × 20 MW` сначала сравни документы и ветки: `main` имеет лимит `20000000/60` Дж/тик **на мост**, экспериментальный EM074 — `120000000/60` **на один мост**. Это разные конфигурации! Критерий — полноценный нативный тест **1/2/3/6 параллельных стандартных 20-МВт мостов** от одной заводской к одной контактной сети с измерением фактической передачи и энергетического баланса. Утверждённая политика описана в [PR #81](https://github.com/zukera2-stack/Factorio/pull/81) (документация, не сливать без разрешения).
6. Береги пользовательские исходники, архивы, сохранения и утверждённые PNG; не загружай движок/коммерческие бинарники в публичный GitHub и не создавай релизы/merge без разрешения владельца.

## Источники авторитетности

- **GitHub**: единственный канонический источник текущего исполняемого кода и принятых изменений.
- **ChatGPT Library**: внешняя приватная рабочая коллекция бинарников, исторических оригиналов, тестовых стендов, журналов и снимков; это доступный при наличии прав ресурс, **не Git remote**.
- **Только реальные игровые логи на exact bytes + exact engine**: подтверждение native Factorio QA. Одни имена файлов, теги, статические проверки и создание ZIP не заменяют нативные результаты.
