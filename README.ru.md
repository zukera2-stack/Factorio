**Визуальная геометрия опор 25 кВ принята пользователем в Factorio**, но эксперимент **не объединён с `main`**. Длинная южная и короткая северная опоры с отдельными консолями теперь совпадают по высоте подвесов; поправка северного варианта — `NORTH_DROP=2.02`. Все 12 PNG версии `039` перенесены в GitHub без перерисовки и сверены по SHA-256. [Экспериментальная ветка](https://github.com/zukera2-stack/Factorio/tree/experiment/25kv-visual-042-accepted) · [Игровое свидетельство](docs/tests/catenary-visual-0.1.42-user-accepted-2026-11-18.md) · [Аудит файлов](docs/FILE_RELEVANCE_042.md).

**Стабильная `main` остаётся 0.1.24.** В эксперименте 0.1.42 на прямых ВСМ скрытые штатные соединители и собственные контактный/несущий провода со струнами; на кривых — пока видимый ванильный провод. Ограничения: **32 / 16 / 40 клеток**. Реальной передачи электрической мощности (`MW`) нет. Принятие внешнего вида не означает, что все сценарии Undo/Redo, поворотов и рельсовой связности повторно проверены.

# Electrified Mainline

Мод для **Factorio 2.1**: высокоскоростные рельсы, опоры контактной сети 35 кВ и в перспективе электрическая тяга, аккумуляторы и рекуперация.

**Основная принятая версия — 0.1.24.** Проверена пользователем в **Factorio 2.1.20 (build 87512)** на сохранении «ВСМ». Визуальная архитектура опор C уже объединена с `main` через [PR №8](https://github.com/zukera2-stack/Factorio/pull/8): видимая решётчатая стойка при установке, восемь автоматически ориентируемых консолей, цветные призраки, работа дронов и Undo/Redo, иконка из южного спрайта и ненавязчивые круглые маркеры. [Отчёт по тесту](docs/tests/catenary-mast-0.1.24-user-accepted-2026-11-15.md) · [ZIP 0.1.24 в GitHub Actions](https://github.com/zukera2-stack/Factorio/actions/runs/43748406702/artifacts/14175755233).

**Важно:** контактные провода пока **только изображаются**. Энергия по ним не передаётся (`transfer_MW=0`), электротяга, батареи и рекуперация не реализованы. Это принятая **визуальная веха**, а не завершённый мод.

Проверенная ранее версия **0.1.8** остаётся как историческая точка отката и доказательство штатного Upgrade Planner + Undo/Redo для прямых и двух типов кривых рельсов. Не все эти сценарии повторно регрессионно проверялись в 0.1.24. [Тесты 0.1.8](docs/tests/undo-0.1.8-2026-11-12.md).

## Текущая конструкция опоры 35 кВ

- Нативная стойка C в `electric-pole.pictures` видна под курсором и в призраке.
- Восемь отдельных консолей/изоляторов поворачиваются к ближайшему ВСМ-пути по RailEnd-геометрии; у призрака консоль рисуется отдельно с голубым оттенком.
- Установка/демонтаж, дроны, копирование чертежей и Undo остаются штатными.
- Статическая графика опор и результаты PNG-тестов находятся в репозитории; полноразмерные старые варианты C сохранены для отката.

Следующий этап — **красивые контактный и несущий провода по ВСМ**, затем отдельная разработка реального электроснабжения. [Актуальное состояние](docs/STATUS.md) · [архитектура](docs/ARCHITECTURE.md) · [сводка для продолжения](docs/AI_CONTEXT.md).

## Идея мода

Проект развивается вокруг следующих возможностей:

- прямые, кривые и полудиагональные высокоскоростные рельсы;
- электровоз с аккумуляторным резервом;
- упрощённая игровая модель контактной сети;
- рекуперативное торможение;
- специализированный подвижной состав;
- локализация на английском и русском языках.

Это цели проекта, а не утверждение, что все функции уже работают. Реальное состояние реализации описано в [docs/STATUS.md](docs/STATUS.md).

## Требования

- Factorio **2.1**
- Зависимость из метаданных: `base >= 2.1.0`
- В комментариях исходников упоминается Space Age, но обязательность дополнения пока не подтверждена метаданными мода.

## Установка для проверки

Для 0.1.24 скачай [артефакт GitHub Actions](https://github.com/zukera2-stack/Factorio/actions/runs/43748406702/artifacts/14175755233), извлеки вложенный `ElectrifiedMainline_0.1.24.zip` и положи **только внутренний ZIP** в папку `mods`. [ZIP 0.1.8](dist/ElectrifiedMainline_0.1.8.zip) оставлен для исторического отката.

Для теста:

1. Сделай резервную копию сохранения.
2. Скопируй архив в папку модов Factorio.
3. Включи мод в меню Mods.
4. Проверь его на отдельном тестовом сохранении и посмотри лог, если загрузка завершится ошибкой.

Пока прототип не прошёл проверку, не стоит подключать его к основному сохранению.

## Разработка

Исходники находятся в `ElectrifiedMainline/` — это самостоятельная папка мода Factorio. Файл `info.json` должен оставаться непосредственно в её корне.

Перед выпуском новой версии необходимо:

1. Для каждой нетривиальной механики, проблемы совместимости или обходного решения скопировать [шаблон исследования](docs/PROTOTYPE_RESEARCH_TEMPLATE.md) в `docs/research/` и заполнить его до написания кода. Следовать [протоколу исследования аналогов](docs/RESEARCH_METHOD.md): изучить работающие ванильные и однотипные модовые прототипы, сверить API целевой версии и сравнить их с нашим исходником.
2. Проверить загрузку с базовой игрой и с предполагаемым набором дополнений.
3. Протестировать размещение и демонтаж объектов, создание поездов, объединение и разделение составов, сохранение и загрузку игры.
4. Собрать ZIP, содержащий **ровно одну папку мода** в соответствии с текущим CI: `ElectrifiedMainline/info.json` в корне архива. Workflow пакует `ElectrifiedMainline/` без двойной вложенности. Файл `info.json` не должен лежать непосредственно в корне ZIP без папки мода.
5. Синхронно обновить `CHANGELOG.md` и версию в `info.json`.

## Метод работы над модом

Для разработчиков и ИИ-агентов обязателен [регламент вклада](CONTRIBUTING.md) и [AGENTS.md](AGENTS.md): сначала найти рабочий штатный или однотипный модовый аналог, изучить исходники, сверить требования с официальным API целевой версии, сравнить с нашим кодом и только затем вносить минимальное изменение. Не угадывать флаги и не считать успешную сборку доказательством работы в игре.
