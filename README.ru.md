# Electrified Mainline

Мод для Factorio 2.1: экспериментальный проект высокоскоростной железнодорожной инфраструктуры, электровоза, резервной батареи и рекуперативного торможения.

> **Состояние проекта: проверенная базовая версия 0.1.8 в `main` (PR №6 объединён).** Factorio 2.1.20, сборка 87512: зелёный планировщик улучшений заменил **26 прямых и 8 кривых рельсов** с работающими Ctrl+Z/Ctrl+Y; наложение чертежа Ctrl+Shift заменило **14 прямых и 8 кривых рельсов**, отмена и повтор действия сработали. Опасная экспериментальная привязка к Undo удалена. Полудиагональные рельсы, отдельный инструмент замены и прерываемые задания роботов ещё не проверены; электротяга, аккумуляторы, контактная сеть и рекуперация пока не реализованы. См. [состояние разработки](docs/STATUS.md) и [отчёт об испытаниях](docs/tests/undo-0.1.8-2026-11-12.md).

## Идея мода

Проект развивается вокруг следующих возможностей:

- прямые, кривые и полудиагональные высокоскоростные рельсы;
- электровоз с аккумуляторным резервом;
- упрощённая игровая модель контактной сети;
- рекуперативное торможение;
- специализированный подвижной состав;
- локализация на английском и русском языках.

Это цели проекта, а не утверждение, что все функции уже работают. Реальное состояние реализации описано в [docs/STATUS.md](docs/STATUS.md).

## Требования

- Factorio **2.1**
- Зависимость из метаданных: `base >= 2.1.0`
- В комментариях исходников упоминается Space Age, но обязательность дополнения пока не подтверждена метаданными мода.

## Установка для проверки

Для версии 0.1.8 можно использовать [проверенный архив 0.1.8](dist/ElectrifiedMainline_0.1.8.zip) из репозитория либо успешный артефакт **Build Factorio mod ZIP** в [GitHub Actions](https://github.com/zukera2-stack/Factorio/actions/workflows/build-mod.yml) (название `ElectrifiedMainline-test-build`). Старый архив `mods/ElectrifiedMainline_0.1.0.zip` — историческая версия. Контрольная сумма ZIP и коммит проверенного исходника записаны в [BUILD_018.yaml](docs/BUILD_018.yaml).

Для теста:

1. Сделай резервную копию сохранения.
2. Скопируй архив в папку модов Factorio.
3. Включи мод в меню Mods.
4. Проверь его на отдельном тестовом сохранении и посмотри лог, если загрузка завершится ошибкой.

Пока прототип не прошёл проверку, не стоит подключать его к основному сохранению.

## Разработка

Исходники находятся в `ElectrifiedMainline/` — это самостоятельная папка мода Factorio. Файл `info.json` должен оставаться непосредственно в её корне.

Перед выпуском новой версии необходимо:

1. Для каждой нетривиальной механики, проблемы совместимости или обходного решения скопировать [шаблон исследования](docs/PROTOTYPE_RESEARCH_TEMPLATE.md) в `docs/research/` и заполнить его до написания кода. Следовать [протоколу исследования аналогов](docs/RESEARCH_METHOD.md): изучить работающие ванильные и однотипные модовые прототипы, сверить API целевой версии и сравнить их с нашим исходником.
2. Проверить загрузку с базовой игрой и с предполагаемым набором дополнений.
3. Протестировать размещение и демонтаж объектов, создание поездов, объединение и разделение составов, сохранение и загрузку игры.
4. Собрать ZIP, содержащий **ровно одну папку мода** в соответствии с текущим CI: `ElectrifiedMainline/info.json` в корне архива. Workflow пакует `ElectrifiedMainline/` без двойной вложенности. Файл `info.json` не должен лежать непосредственно в корне ZIP без папки мода.
5. Синхронно обновить `CHANGELOG.md` и версию в `info.json`.

## Метод работы над модом

Для разработчиков и ИИ-агентов обязателен [регламент вклада](CONTRIBUTING.md) и [AGENTS.md](AGENTS.md): сначала найти рабочий штатный или однотипный модовый аналог, изучить исходники, сверить требования с официальным API целевой версии, сравнить с нашим кодом и только затем вносить минимальное изменение. Не угадывать флаги и не считать успешную сборку доказательством работы в игре.
